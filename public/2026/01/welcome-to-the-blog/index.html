Welcome to the Blog

Friday, 2 January, 2026 | 1 min read
welcome hugo

Hello, and welcome. This is the first post on a brand-new blog, which means it is mostly a promise about what comes next rather than a finished thing.

What to expect

I plan to write here about three broad topics:

  1. Software — things I build, tools I like, and lessons learned the hard way.
  2. Books — short reactions to what I’m reading, tracked in the library.
  3. Notes — quick, half-formed thoughts that don’t deserve a full post.

How this site is built

This site is generated with Hugo using the Kana theme. That means every page you read started life as a Markdown file. Writing a post is as simple as creating a new file and running the dev server.

If you’d like to follow along, subscribe to the RSS feed. See you in the next one.
